# DEAD MONEY: Turf Wars

**A gritty fictional 1990s crime-trading strategy game.** Two rival simulated dealers compete to build the highest net worth in 30 days, while shifting markets, gangs, raids and debt complicate the journey.

## Play locally

Download [index.html](index.html) and open it in a modern browser. No installation, server or API key required.

- **PLAY ONE DAY** advances both rivals one turn.
- **AUTO PLAY** runs the match automatically.
- **NEW MATCH** resets the simulation.
- **EXPORT SAVE / IMPORT SAVE** moves a versioned JSON save between browsers.
- Progress is also saved in local browser storage.

> **Important:** GPT and CLAUDE are currently *names for two scripted strategies*, **not live AI models**. Genuine model adapters are planned and must use secure server-side credentials.
