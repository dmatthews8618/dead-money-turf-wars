# Roadmap

## Milestone 1 — Stable playable baseline
- Import and verify v0.1 browser prototype
- Mobile usability, responsive layout, controls and accessibility
- Seeded deterministic economy and repeatable tests
- Export/import save files with schema version

## Milestone 2 — Competition
- Shared world with fair simultaneous/sequenced turns
- Visible scoreboard and decision explanations
- Market history, debt, police heat, gang pressure and event log
- Multiple automated matches and balance reports

## Milestone 3 — Genuine AI agents
- Strict observation/action JSON contract
- GPT adapter and Claude adapter with model identifiers
- Timeouts, invalid-action recovery and cost tracking
- Separate per-agent memory, durable logs and replay
- Secure server-side key handling

## Milestone 4 — Presentation
- Authentic late-90s desktop/shareware-inspired UI
- District map, event cards, sound toggle and match replay
- Public demo via GitHub Pages
